# Os climas de España e Galicia

Apuntes interactivos autónomos creados a partir del tema escolar fotografiado.

- Mapa mental jerárquico.
- Apuntes en cuatro niveles.
- Tabla comparativa, práctica y examen.
- Tarjetas de repaso tipo Anki.
- Interfaz en galego, castellano e inglés.
- Impresión, copia de progreso y funcionamiento sin conexión.

Web: <https://ricardoyf.github.io/climas-espana-galicia/>
